# Spring Boot Learning Project

This repository is a beginner-friendly Spring Boot project created for learning purposes. It covers the basics of building RESTful APIs using Spring Boot, Maven, and Java.

## 🚀 Technologies Used

- Java 17 (or your version)
- Spring Boot (latest stable version)
- Maven
- Spring Web
- Spring Data JPA
- H2 Database (for development/testing)
- Lombok

## 🛠️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Java JDK 17+
- Maven
- IDE like IntelliJ IDEA or Eclipse
